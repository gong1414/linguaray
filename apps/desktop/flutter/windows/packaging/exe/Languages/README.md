# Inno Setup translation

ChineseSimplified.isl comes from the Inno Setup `is-6_7_1` tag,
`Files/Languages/Unofficial/ChineseSimplified.isl` in
https://github.com/jrsoftware/issrc at commit
`cfdf48923178df4b4f040e038b423aa555a61ffc`. That pinned compiler does not ship this
translation in its default Languages folder.

The original translator attribution is retained in the file. Only trailing
whitespace and line endings were normalized. The upstream Inno Setup license
is included alongside it and installed with LinguaRay.
