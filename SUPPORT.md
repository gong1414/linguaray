# Support

- Use [GitHub Discussions](https://github.com/gong1414/linguaray/discussions)
  for installation help, provider setup, and general questions.
- Use the structured [issue forms](https://github.com/gong1414/linguaray/issues/new/choose)
  for reproducible bugs and focused feature requests.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

LinguaRay is maintained by the community without guaranteed response times.
Please include the app version, operating system version, relevant logs with
secrets removed, and concise reproduction steps when requesting help.
